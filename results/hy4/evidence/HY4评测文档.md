## 2. 方法

**分块策略。** 三批长文均超出单次上下文，采用「检索定位 + 分段读取」，等效长文截断/分段输入，与对照模型全文粘贴方式不同，已逐行写入 `deviation_note`：

| 材料 | 规模 | 策略 |
|---|---|---|
| T2/T4 财报 4 份 | 0.34–1.42 MB | 关键词检索（三大报表名、指标名）定位行区间，再分段精读，页码按 `===== PAGE n =====` 反查 |
| 硬档 T6 长安法律意见书 | 122 KB / 67 页 | 章节标题检索 + 分段定位 |
| T7 扫描件 | 19 张无文本层 PNG | 逐页视觉 OCR；横向表格页旋转视角判读，小字号数字 2–4 倍放大核读；未调用外部 OCR 引擎 |
| REITs 任务A | 16 份年报 | 按 `===== PAGE n =====` 切页，三层规则化抽取：① 4.1.2/4.1.3 运营指标表块解析（单位行 + 连续数值行）；② 3.1/3.3.1/4.3.1 财务表正则；③ 叙述句补充（特许经营剩余年限、车流量等） |
| REITs 任务B | 1511 页 / 1,291,655 字符 | **100 页/块 × 16 块**（末块 11 页），逐块关键词正则扫描并落盘命中页清单（`reits/_audit/candidates.txt`、`reits/_audit/chunk_stats.json`）；合并跨块命中页后精读定位；回填后统一自检；块统计见 `reits/_audit/chunk_stats.json` |

**页码定位。** 一律取所给材料 `===== PAGE n =====` 的 `n`（从 1 计的物理页序）。页内印刷页码常比物理页小 1，已按物理页标记为准。T7 按文件名 `pNNNN` 取物理页序号（p0194 页内印 193）。20-F 为 HTM/XBRL 无物理页标记，按任务书契约填 `page=0`；T1 理想 HTM 填 0、赛力斯 PDF 填 1。写出前逐条自检：页码 ∈ [1, 总页数] 且该页文本存在与 `value` 数值等价的数字 token；任务B 另对字符串字段做原文/去空白严格匹配。

> **页码体系差异（请 lead 复核时注意）**：所给材料 `===== PAGE n =====` 是文本侧页序号（如 2021 招股书 626 个标记、赛力斯年报 224 个标记），与 `groundtruth/` 中 GT 标注的原 PDF 页号（如招股书 472/474/478）**不是同一编号体系**。HY4 严格按任务书/REITs 说明要求使用材料页标记。`score.py` 的字段匹配不使用 page，故不影响 F1；若单独统计页码准确率，请先按材料页标记归一。

**弱项。** ① 长文分段读取造成召回缺口，`li_hk_listing_doc_2021__T2` 漏 9 个字段且 `total_equity FY2019` 取错行丢负号，是全档最明显失误；分段检索对「不在关键词命中页」的字段不鲁棒。② 重点指标覆盖不均衡：REITs WALT/出租率/租金单价/收缴率集中在产权类，特许经营与特殊业态（供热、水利、数据中心、农贸市场、季报）字段明显偏少；续租率全库 0 条、剩余收费年限仅 1 条。③ 整体运营指标表用原文标题词「不动产项目整体」作项目名，与可能期望的具体底层项目名不完全一致。④ T5 无数据标签图表依赖坐标轴估读，引入约 1% 误差。⑤ 无 GUI 界面与用量面板，截图项只能透明降级，是本次最实质的环境不可比因素；若评分流程硬性要求界面/用量截图原件，本批次无法提供，需在横评表单独标注。

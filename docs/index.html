看懂这张表

九档各考什么 · 白话版

术语一句话

Overall
7 个计数档的平均分，综合排名依据。
F1
抽得准 × 抽得全的调和平均——既不能漏，也不能编。
召回 Recall
标准答案里的字段，模型找出来多少比例。
幻觉率
输出里"原文根本没有"的字段占比，越低越好（明细指标，不在主表）。
⚠ REITs 两档没有逐字段标准答案，分数衡量的是输出质量与覆盖（字段名规范、页码齐全、稀缺指标覆盖），1 分 ≠ 数值全对。这是 v1.0 如实声明的口径折中。
04

让你的模型上榜

把仓库地址发给它就行

跑冻结任务

有 API 用零依赖 runner；只有聊天界面用逐字任务包。47 实例，prompt 一字不改。

python scripts/run_eval.py \ --base-url … --model … \ --out results/<slug>/outputs

脚本评分

确定性评分器算分，附上你的 GitHub 用户名；校验器重算比对，防手改。

python scripts/score_all.py \ --slug <slug> --name "模型" \ --submitter <GitHub用户名>

PR 留分

CI 自动重算你的输出；合并后分数永久留在排行榜与本页。

git checkout -b result/<slug> git add results/<slug> … # 开 PR → CI 绿 → 合并上榜
阅读完整协议 AGENTS.md → 诚信规则：被测模型只能看到任务输入，不得接触标准答案与评分脚本。

# 数据说明

## 1. 来源（全部官方一手披露）

| 市场 | 来源 | 文档类型 |
|---|---|---|
| 美股 | SEC EDGAR（CIK 1791706 等） | 20-F、6-K EX-99.1（交付/业绩公告） |
| 港股 | 港交所披露易 (hkexnews) | 年报、招股书（全球发售）、业绩公告 |
| A 股 | 巨潮资讯 (cninfo) | 年报、产销快报、法律意见书、扫描件（批复/盖章页） |
| REITs | 上交所/深交所 REITs 信息披露平台 | 定期报告（年报/中报/季报）、招募说明书 |

`data/manifest.json` 逐文档记录：来源 URL（汽车档）、原文 sha256、原文文件名、页数、抽取文本/页面图像路径与哈希、备注。
REITs 原文 PDF 未记录直链（交易所平台检索式披露），manifest 给出基金代码+报告名+原文哈希供检索核对。

## 2. 仓库内包含什么

- **官方评测输入**（参评必需，已含）：
  - `data/text/`：21 份抽取文本（带 `===== PAGE n =====` 物理页标记），约 3.4MB
  - `data/pages/`：24 张页面 PNG（T5 图表页 + T7 扫描页），约 8.9MB
  - `data/reits/`：16 份 REITs 定期报告文本 + 1511 页招募书文本，约 6.7MB
- **不包含**：原文 PDF/HTM 二进制（总计 ~450MB，避免仓库膨胀）。
  可选下载：`python scripts/fetch_corpus.py` → `corpus_original/`，逐文件 sha256 校验。
  原文仅用于复核与可选 pdf_native 模式；**不下载也能完整参评**。

## 3. 抽取方法（可复现）

- PDF：pymupdf `get_text("text")` 逐页拼接，页标记 `\n\n===== PAGE n =====\n\n`（n 从 1 计）。
- HTM：lxml 去标签保留正文（SEC 文件含内联 XBRL，抽取时忽略标签）。
- 页面图像：pymupdf 渲染 PNG（T5/T7 指定页）。
- 扫描件验证：text_chars < 200/页 且 image_count > 0 才纳入 T7。

## 4. 许可与版权

- 原始披露文件：版权归披露主体（上市公司/基金管理人/监管机构）。全部为依法公开披露文件，
  本仓库以研究/评测目的引用其公开内容，注明来源与哈希；若权利方提出异议将及时移除。
- 抽取文本/页面图像（衍生数据）与 GT 标注：**CC BY 4.0**。
- 代码/评分器/prompt 编排：**Apache-2.0**。

## 5. 数据完整性

- 所有输入文件 sha256 锁在 `benchmark.json.hashes.inputs`；GT 锁在 `hashes.groundtruth`。
- `python scripts/freeze_benchmark.py --check` 一键校验。
- 发现数据错误（GT 标注错/抽取损坏）：提 issue → 维护者核实 → 升版本修正（不私改）。

## 6. 语料规模背景

原工程语料：汽车 84 份（34 PDF + 50 HTM）+ 硬档 8 份 + REITs 78 份定期报告 + 1511 页招募书。
本开源 v1.0 冻结其中 **47 个实例所需的输入**（REITs 取 16+1 子集，与参考横评一致）；
其余语料（比亚迪/蔚来/小鹏/零跑扩展档、REITs 全量 78 份）保留在原研究工程，未来版本可扩充。
